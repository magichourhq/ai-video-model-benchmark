# Commercial Image-to-Video Model Benchmark via Magic Hour

This dataset contains 60 controlled image-to-video attempts requested through the Magic Hour API: four original commercial scenarios, five named video models, and three attempts per scenario-model pair. It includes 58 completed MP4 outputs, two preserved provider failures, four original input images, exact prompts, API outcome metadata, charged credits, and checksums.

Magic Hour AI, Inc. designed, funded, and published the study and provides the API used to access every evaluated model. Read `README.md`, `FINDINGS.md`, and `MEDIA-LICENSE.md` before use. Completion status is not an aesthetic score, and the dataset does not declare a quality winner.
